# 영어로 문장 만들기 훈련 · 인터랙티브 트레이너

『영어로 문장 만들기 훈련』(사람in) 시리즈로 **한국어 → 청크 누적 확장** 영작 훈련을 하는 단일 HTML 앱입니다.
파일 하나로 오프라인에서 동작하며, 설치가 필요 없습니다.

## 훈련 방식

책의 핵심은 영어 문장 암기가 아니라 한국어 어순 덩어리를 하나씩 쌓아 올리며 영어를 붙여 나가는 것입니다.

```
한국어 문장   나는 체중을 줄이려고 매일 아침 공원에서 달립니다.
뼈대 + 확장   [나는 달립니다] + [공원에서] + [매일 아침] + [체중을 줄이려고]

1  나는 달립니다                          [        ]  ● run
2  나는 달립니다 / 공원에서                 [        ]  ● in the park
3  … / 매일 아침                          [        ]  ● every morning
4  … / 체중을 줄이려고                     [        ]  ● lose weight
                    Ans. I run in the park every morning to lose weight.
```

한 줄씩만 열리고, Enter로 확인하면 다음 줄이 열립니다. 한 줄이라도 틀리면 그 문장은 오답으로 기록됩니다.

## 학습 모드

| 모드 | 내용 | 한국어 데이터 필요 |
|---|---|---|
| 누적 확장 | 위의 단계별 드릴 | ✔ |
| 한→영 영작 | 한국어 문장만 보고 통째로 영작 | ✔ |
| 청크 조립 | 청크 타일을 어순대로 클릭 | ✔ |
| 어순 조립 | 단어 단위 어순 맞추기 | — |
| 받아쓰기 | TTS 듣고 타이핑 | — |
| 전체 보기 | 문장 목록 + 본문 에세이 | — |

그 밖에 유닛별 학습지 인쇄, 진도·정답률·즐겨찾기·오답노트(localStorage), STEP 필터, 검색, 다크/라이트 테마를 지원합니다.

## 데이터 현황

| 교재 | 한국어·청크 완료 |
|---|---|
| 1차 임계점 | 860 / 860 (100%) |
| 2차 임계점 | 756 / 1,059 |
| 3차 임계점 | 0 / 756 |
| 일상 표현편 | 0 / 809 |
| **합계** | **1,616 / 3,484** |

한국어가 아직 없는 문장은 앞의 세 모드가 비활성화되고, 어순 조립·받아쓰기로는 그대로 연습할 수 있습니다.

## 구조

```
index.html          빌드 결과물 (이 파일만 열면 됩니다)
src/
  data.json         197유닛 3,484문장 (id = book:유닛인덱스:문항인덱스)
  ko_*.json         한국어·청크 배치 파일
  ko_all.json       배치 병합 결과
  template2.html    앱 템플릿 (__DATA__ / __KO__ 자리표시자)
  merge_ko.py       배치 병합 + 검증
  build.py          템플릿에 데이터 주입 → HTML 생성
  repair.py         2단 조판 PDF에서 어긋난 STEP 블록 재배치
```

### 빌드

```bash
cd src
python merge_ko.py    # 배치 병합 + 청크 검증
python build.py       # HTML 재생성
```

### 데이터 형식

```json
"c1:0:0": {
  "ko": "나는 체중을 줄이려고 매일 아침 공원에서 달립니다.",
  "c": [["나는 달립니다", "I run", "run"],
        ["공원에서", "in the park", "in the park"],
        ["매일 아침", "every morning", "every morning"],
        ["체중을 줄이려고", "to lose weight", "lose weight"]]
}
```

각 청크는 `[한국어 청크, 영어 청크, 힌트 키워드]`입니다.
**검증 규칙**: 영어 청크를 순서대로 이어 붙이면 정답 문장과 정확히 일치해야 하며, `merge_ko.py`가 매 빌드마다 전수 검사합니다.
