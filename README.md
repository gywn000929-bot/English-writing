# 영어로 문장 만들기 훈련 · 인터랙티브 트레이너

『영어로 문장 만들기 훈련』(사람in) 시리즈로 **한국어 → 청크 누적 확장** 영작 훈련을 하는 단일 HTML 앱입니다.
파일 하나로 오프라인에서 동작하며, 설치가 필요 없습니다.

## 훈련 방식

책의 핵심은 영어 문장 암기가 아니라 한국어 어순 덩어리를 하나씩 쌓아 올리며 영어를 붙여 나가는 것입니다.

```
한국어 문장   나는 체중을 줄이려고 매일 아침 공원에서 달립니다.
뼈대 + 확장   [나는 달립니다] + [공원에서] + [매일 아침] + [체중을 줄이려고]

1  나는 달립니다                          [        ]  ● run
2  나는 달립니다 / 공원에서                 [        ]  ● in the park
3  … / 매일 아침                          [        ]  ● every morning
4  … / 체중을 줄이려고                     [        ]  ● lose weight
                    Ans. I run in the park every morning to lose weight.
```

한 줄씩만 열리고, Enter로 확인하면 다음 줄이 열립니다. 한 줄이라도 틀리면 그 문장은 오답으로 기록됩니다.

## 학습 모드

| 모드 | 내용 | 한국어 데이터 필요 |
|---|---|---|
| 누적 확장 | 위의 단계별 드릴 | ✔ |
| 한→영 영작 | 한국어 문장만 보고 통째로 영작 | ✔ |
| 청크 조립 | 청크 타일을 어순대로 클릭 | ✔ |

| 받아쓰기 | TTS 듣고 타이핑 | — |
| 전체 보기 | 문장 목록 + 본문 에세이 | — |
| ⚡ 스피드런 | 60초 타임어택, 콤보·최고 기록 | — |

### AI 첨삭 (선택)

교재 정답은 여러 정답 중 하나일 뿐이라, 다르게 써도 맞는 경우가 많습니다.
상단 `✨ AI` 에서 본인의 Anthropic API 키를 등록하면 채점 뒤 **AI 첨삭** 버튼이 생깁니다 —
한국어 뜻을 정확히 전달하고 어법이 자연스러우면 교재와 표현이 달라도 정답으로 판정합니다.
키 없이도 **내 답도 정답** 버튼으로 직접 인정할 수 있고, 인정한 표현은 저장되어 다음부터 자동으로 정답 처리됩니다.

키는 브라우저 localStorage에만 저장되며 요청은 api.anthropic.com으로 직접 갑니다. 공용 PC에서는 권하지 않습니다.

그 밖에 유닛별 학습지 인쇄, 진도·정답률·즐겨찾기·오답노트(localStorage), STEP 필터, 검색, 다크/라이트/파스텔 핑크 테마를 지원합니다.

**모바일 대응** — 폰에서는 유닛 목록과 학습 옵션이 접혀 있고 상단 `☰ 유닛` / `⚙ 옵션` 버튼으로 펼칩니다.
누적 확장 표는 한 줄씩 세로로 쌓이며, 입력칸은 16px로 두어 iOS에서 자동 확대되지 않습니다.

## 폰에 설치해서 쓰기

사이트를 연 뒤 브라우저 메뉴에서 **홈 화면에 추가**(Android: 앱 설치 / iOS: 공유 → 홈 화면에 추가)를 누르면
앱처럼 전체 화면으로 열리고, 서비스 워커가 캐시해 두어 **비행기 모드에서도 그대로 동작**합니다.

## 진도 옮기기

학습 기록(진도·정답률·즐겨찾기·오답노트·스피드런 최고 점수·인정한 답)은
브라우저의 localStorage에 저장돼 **기기마다 따로** 관리됩니다.
상단 `💾 진도` 에서 파일로 내보내고 다른 기기에서 가져오면 이어서 할 수 있습니다.

가져오기는 덮어쓰지 않고 **합칩니다** — 맞힌 횟수는 큰 값을 남기고, 즐겨찾기·인정한 답·최고 점수는 모두 보존합니다.

## 구조

```
index.html          빌드 결과물 (이 파일만 열면 됩니다)
src/
  data.json         198유닛 3,504문장 (id = book:유닛인덱스:문항인덱스)
  ko_*.json         한국어·청크 배치 파일
  ko_all.json       배치 병합 결과
  template2.html    앱 템플릿 (__DATA__ / __KO__ 자리표시자)
  merge_ko.py       배치 병합 + 검증
  build.py          템플릿에 데이터 주입 → HTML 생성
  repair.py         2단 조판 PDF에서 어긋난 STEP 블록 재배치
```

### 빌드

```bash
cd src
python merge_ko.py    # 배치 병합 + 청크 검증
python build.py       # HTML 재생성
```

### 데이터 형식

```json
"c1:0:0": {
  "ko": "나는 체중을 줄이려고 매일 아침 공원에서 달립니다.",
  "c": [["나는 달립니다", "I run", "run"],
        ["공원에서", "in the park", "in the park"],
        ["매일 아침", "every morning", "every morning"],
        ["체중을 줄이려고", "to lose weight", "lose weight"]]
}
```

각 청크는 `[한국어 청크, 영어 청크, 힌트 키워드]`입니다.
**검증 규칙**: 영어 청크를 순서대로 이어 붙이면 정답 문장과 정확히 일치해야 하며, `merge_ko.py`가 매 빌드마다 전수 검사합니다.
